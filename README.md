# Air Quality Analysis in New York using R

Mini project for R Programming Lab (26CAP-632), MCA (Data Science), Chandigarh University.

## Project Overview
Exploratory data analysis and regression on the built-in `airquality` dataset
(New York, May–September 1973) to predict Ozone from Temperature, Wind and Solar Radiation.

## What the script does
- Cleans the data (removes missing values)
- EDA: histograms, boxplots, scatter plots, correlation
- t-test: early summer vs peak summer ozone
- Linear and polynomial regression, compared with R², adjusted R² and RMSE

## How to run
1. Install R and RStudio
2. Open `air_quality_project.R` in RStudio
3. Click **Source**. No dataset file is needed.
